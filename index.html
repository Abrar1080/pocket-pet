👯 Friends need Supabase

Friend rooms, real chat, and online races need the free Supabase backend. Right now this game is in local mode, so no fake friends are shown here.

Follow README-SETUP.md (free, no card): create a Supabase project, run schema.sql, paste the URL + anon key into config.js — then friends unlock.
